# JiokyeTanks-Multiplayer

This repository now contains two implementations:

- `TankBattleMultiplayer/` – the original Android Java version.
- `GodotV2/` – a new Godot 4 based Version 2 recreation with a modernized flow and UI foundation.

## Running Version 2 (Godot)

1. Open Godot 4.x.
2. Import the project from:
   `/home/runner/work/JiokyeTanks-Multiplayer/JiokyeTanks-Multiplayer/GodotV2/project.godot`
3. Run the main scene (`scenes/ui/main_menu.tscn`).

### V2 Controls

- Move: `W A S D`
- Shoot: `Mouse Left` or `Space`
- Return to menu after match end: `Enter` or `Shoot`
